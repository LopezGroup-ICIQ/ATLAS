atlas.core.filtering.structure_filters.apply_filter_dft_converged(struct: Atoms, require_scf: bool = True, require_ionic: bool = False, remove_unknown: bool = False) → bool

Detect structures whose DFT calculation is not converged.

Missing convergence keys mean “unknown”; they are kept unless remove_unknown is set.

Parameters:

  • struct (ase.Atoms) – Structure to check.

  • require_scf (bool, optional) – Require explicit SCF convergence.

  • require_ionic (bool, optional) – Require explicit ionic convergence for relaxation calculations. Static calculations are unaffected.

  • remove_unknown (bool, optional) – Also flag structures whose convergence metadata is missing.

Returns:

True when the structure should be removed.

Detect structures split into disconnected fragments.

A first-neighbour graph is built from ASE natural covalent cutoffs. A structure is flagged when its largest connected component contains less than min_largest_fraction of the atoms, or when the number of components exceeds max_components.

Parameters:

  • struct (ase.Atoms) – Structure to check.

  • cov_rad_multiplier (float, optional) – Multiplier applied to the natural covalent cutoffs.

  • min_largest_fraction (float, optional) – Minimum allowed fraction of atoms in the largest component.

  • max_components (int, optional) – Optional hard limit on the number of connected components.

Returns:

True when the structure is fragmented.

Return type:

bool

atlas.core.filtering.structure_filters.find_duplicate_structures(structures: list[Atoms], *, r_cut: float = 4.0, n_max: int = 4, l_max: int = 4, similarity_threshold: float = 0.999, group_by_phase: bool = True, n_jobs: int = -1, progress: bool = True) → DuplicateOutcome

Detect duplicate structures with SOAP average-kernel similarity.

For two structures i and j the similarity is the normalized average of exp(-||d_a - d_b||^2) over all atom-descriptor pairs (a, b). This matches dscribe.kernels.AverageKernel(metric='rbf', gamma=1) while avoiding an N x N kernel matrix.

Structures are grouped by phase (optional), atom count, and composition, then visited in input order. A structure is marked as a duplicate when it is similar to an earlier kept structure in the same group.

Parameters:

  • structures (list of ase.Atoms) – Structures to compare.

  • r_cut (float, optional) – SOAP cutoff radius in Angstrom.

  • n_max (int, optional) – Number of radial basis functions.

  • l_max (int, optional) – Maximum angular momentum.

  • similarity_threshold (float, optional) – Minimum similarity to consider two structures duplicates.

  • group_by_phase (bool, optional) – Compare structures only within the same phase.

  • n_jobs (int, optional) – Number of parallel jobs passed to dscribe.

  • progress (bool, optional) – Show progress bars for descriptor generation and comparison.

Returns:

Indices of structures to remove and the matched pairs with their similarity values.

Return type:

DuplicateOutcome
