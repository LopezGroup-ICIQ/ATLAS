class atlas.active_learning.backends._base.DescriptorBatchState(*args, **kwargs)

Bases: Protocol

State for one differentiable descriptor evaluation.

Produced by DifferentiableDescriptorHandle.prepare() and consumed by DifferentiableDescriptorHandle.descriptors(). It bundles the leaf tensors an optimizer differentiates with respect to together with the neighbour-list data that geometric penalty terms need.

Tensor types are spelled Any so that this module stays free of a torch import; in practice every attribute is a torch.Tensor.

cell: Any

(3, 3) lattice vectors, strained when strain is present.

edge_index: Any

(2, n_edges) sender/receiver indices of the neighbour list.

free_positions: Any

(n_atoms, 3) unstrained positions. Identical to positions when strain is None; otherwise the leaf that positions derives from.

positions: Any

(n_atoms, 3) Cartesian positions. A leaf with requires_grad=True when the cell is fixed, or a strained (non-leaf) tensor when strain is the leaf being optimized.

shifts: Any

(n_edges, 3) Cartesian periodic-image offset for each edge.

strain: Any

(3, 3) strain leaf, or None when the cell is held fixed.

class atlas.active_learning.backends._base.DifferentiableDescriptorHandle(*args, **kwargs)

Bases: Protocol

A reusable, autograd-connected descriptor evaluator for one model.

Where MLIPDescriptorProvider returns detached numpy arrays for a whole database, this returns a torch tensor that is still attached to the graph, so that d(descriptor)/d(positions) is available. That is what makes latent-space inversion possible: composing it with a trained autoencoder encoder gives a differentiable structure-to-latent map which can be inverted by gradient descent on the positions.

Usage is a two-step cycle, because neighbour lists are fixed when a batch is built and go stale once atoms have moved appreciably:

state = handle.prepare(atoms)
desc = handle.descriptors(state)     # (n_atoms, descriptor_dim)
loss = f(desc, state.positions)
loss.backward()                      # state.positions.grad is now set

Callers that move atoms far must call prepare again to rebuild the neighbour list rather than reusing a stale state.

descriptor_dim: int

Width of the descriptor vector. Must match the input dimension of any model consuming it, e.g. an autoencoder’s first encoder layer.

descriptors(state: DescriptorBatchState) → Any

Return the (n_atoms, descriptor_dim) differentiable descriptors.

The result must match, to numerical precision, what the backend’s MLIPDescriptorProvider.generate_descriptors() produces for the same structure and model – otherwise an inversion would optimize against a different quantity than the one the latent-space map was built from.

device: str

Torch device the tensors live on.

dtype: Any

Torch dtype of the emitted descriptors (spelled Any to avoid a torch import here).

prepare(atoms: Atoms, strain: Any = None) → DescriptorBatchState

Build a batch with a freshly computed neighbour list.

Parameters:

  • atoms (Atoms) – Structure defining the species, cell and current geometry.

  • strain (Any) – Optional (3, 3) strain leaf tensor. When given, positions and cell are deformed by its symmetric part so that gradients flow into the lattice as well. Only meaningful when supports_cell_gradients is True.

Returns:

State to hand to descriptors().

Return type:

DescriptorBatchState

supports_cell_gradients: bool

Whether prepare accepts a strain argument and propagates gradients into the cell.

class atlas.active_learning.backends._base.MLIPConfidenceEstimator(*args, **kwargs)

Bases: Protocol

Protocol for backends whose model gives its own per-structure uncertainty.

Some models (e.g. Orb v3) carry a confidence head that estimates their own force-prediction error, providing a committee-free uncertainty signal. This lets a single pretrained foundation model drive active-learning selection (interpolation.disagreement_check_type = "confidence"), where otherwise only cross-model committee disagreement is available.

Backends without such a head simply omit this protocol; the confidence selection path then raises a clear error naming the backend.

class atlas.active_learning.backends._base.MLIPDifferentiableDescriptorProvider(*args, **kwargs)

class atlas.active_learning.backends._base.MLIPModelCompiler(*args, **kwargs)

Bases: Protocol

Protocol for backends whose models must be compiled before inference.

Some backends (e.g. Allegro/NequIP) cannot run inference from the raw trained checkpoint. It must first be compiled (nequip-compile) into a device-specific artifact. Compilation is expensive and toolchain-sensitive, so it is best done once, on the computer where inference will run, and the compiled artifact reused there.

Backends that need no compilation (e.g. MACE) simply omit this protocol; callers gate on isinstance(backend, MLIPModelCompiler) and, when absent, ship the raw model unchanged.

class atlas.active_learning.backends._base.MLIPPretrainedModel(*args, **kwargs)

Bases: Protocol

Protocol for backends that can serve published pretrained models.

Foundation potentials (MACE-MP/OFF, Orb, fairchem) are not produced by the ATLAS training loop: the “model” is a published identifier such as 'mace:mp-small' or 'orb-v2', which the framework resolves itself (usually a download plus a cache), rather than a file in the working directory.

Users select one through [md.parameters].md_type as '<backend>:<variant>'. find_inference_model gates on this protocol to decide whether to hand create_calculator an identifier or a path.

Backends whose models are always files (e.g. Allegro) simply omit this protocol, and resolution falls back to the on-disk path as before.

Module contents

MLIP backend registry for model-agnostic active learning.

This module provides a registry pattern for MLIP backends. Each backend (MACE, NequIP, Allegro, DeepMD, etc.) registers itself and can then be looked up by name from the TOML configuration.

Usage

from atlas.active_learning.backends import get_backend

backend = get_backend(‘mace’) calculator = backend.create_calculator(model_path, device=’cuda’)

atlas.active_learning.backends.supports_descriptor_gradients(name: str) → bool

Whether a backend can emit autograd-connected descriptors.

Gradient-based features (latent-space inversion, in particular) need the descriptor to stay attached to the autograd graph. Most descriptor paths detach to numpy, so this is a strictly narrower capability than MLIPDescriptorProvider.

Unknown backend names return False rather than raising, so that callers driven by user configuration can gate a feature without a try/except.
